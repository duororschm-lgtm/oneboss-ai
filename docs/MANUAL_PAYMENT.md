# 人工核验微信收款

当前使用客户提供的微信收款码，基础版 ¥1.99、专业版 ¥5.99。新报价读取服务器目录；已有报价和订单保留原快照。增项价格独立计算，订单页以总额为准。

## 客户流程

登录后选择套餐、创建订单。在订单页查看原始收款码，核对收款人 `39(**宇)`，按订单总额付款，并备注订单页展示的八位编号。保存收款码后可在微信扫一扫中从相册识别。付款后提交时间、交易单号等核对信息。提交信息只进入待核验状态，不代表实际收款成功。

## 管理员流程

访问 https://oneboss-ai.onrender.com/dashboard/admin，以已授权账户登录。先在自己的微信账单核对实际到账、金额和备注，再填写真实入账流水并登记确认。确认成功后客户订单页自动刷新，客户可进入制作项目。不得根据客户截图或自报直接确认。

退款需先按核实的原交易实际退回，再在审核页登记真实结果；申请和登记都不会代替微信实际退款。

## 配置

- `MANUAL_PAYMENT_ENABLED=true` 且 `public/payments/wechat-receive.png` 存在时才显示此方式。
- 收款码使用用户授权的原图，无重绘、无修改二维码。
- 平台审核权限通过受信任数据库的 `platform_admins` 管理，普通组织 owner/admin 不能确认收款。无公开提权接口。
- 客户可查看本组织的付款说明；写入由经过认证和订单权限检查的服务端执行。
- 微信 Native 商户支付保持关闭；以后取得商户号后可按 WECHAT_SETUP.md 配置。
