# 客户拍摄向导

## 需要拍多少张？

| 目标质量 | 照片数量 | 可达到效果 |
|---|---|---|
| AI 近似模型 | 1 张 | 可旋转外观，背面为推测 |
| 改善外观细节 | 2-5 张 | 多角度外观，AI 近似 |
| 完整摄影测量 | 20-40+ 张 | 真实外观重建 |

## 推荐拍摄角度

至少覆盖：
- [ ] 正面
- [ ] 背面
- [ ] 左侧面
- [ ] 右侧面
- [ ] 顶部（如可拍摄）
- [ ] 底部（如可拍摄）

## 拍摄技巧

1. **商品静止** — 背景和光线尽量稳定
2. **环绕拍摄** — 以商品为中心，照片间保持较高重叠度（60-80%）
3. **均匀光线** — 避免强烈反光和剧烈曝光变化
4. **细节补充** — 对关键细节增加近景照片
5. **尺度参考** — 放置标尺或已知尺寸的物体

## 什么商品不适合摄影测量？

- 透明/玻璃制品
- 镜面/高反光商品
- 纯色无纹理表面
- 毛绒/半透明材质

→ 这些商品建议提供 CAD 或选择 AI 近似模型

## 上传后系统会告诉你

- 已达到哪个质量等级
- 还缺哪些关键角度
- 是否需要补充尺度参考
- 推荐的建模路线
