结项

AI 自主决定（4 类）

  • 产品事实取舍：哪句话能说、哪句是没依据的承诺
  • 设计方向本身：配色、字体、版式、页面结构
  • 页面与文案的具体写法
  • 发布前自我验收：不达标就不发布

人工必须介入（4 处）

  • 收款核验 — 钱只由人确认
  • 简报批准 — 交付范围由客户认
  • 方向选定 — 品味不可替代
  • 成品验收 — 完成由客户定义

协作方式

  • 每个 Agent 只做一件事，产物是下一个的输入
  • 全部任务落库：角色、阶段、耗时、token、错误码
  • 失败可重试、可回退，人工随时能看到卡在哪
