- Supabase 兼容数据库迁移与 RLS；服务端 Supabase Bearer 身份验证与私有 Storage 接口。

- 资料确认、设计候选选择、生成、定向修改、预览版本、审批、公开路由、多页面、发布失败回退。
- PNG 文件头/尺寸/非空/真实 QR 解码检查、私有 ZIP、manifest、短期下载和验收接口。
- 敏感配置仅环境变量；图片重编码、像素上限、外链限制、权限门禁、请求及任务预算限制。
