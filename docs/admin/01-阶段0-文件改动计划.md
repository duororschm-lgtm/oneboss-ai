# 阶段 0-B｜管理员平台文件改动计划

## 原则

- 只**新增**文件，不改动客户平台的任何现有文件（唯一例外：`src/app/admin/` 目录本身是全新的）。
- 零新增 npm 依赖。
- 后端零改动：不新增 API 路由、不改数据库迁移。

## 新增文件清单

### 数据层 `src/lib/admin/`

| 文件 | 职责 |
| --- | --- |
| `types.ts` | 管理员域类型：订单、退款、核验、指标、审批、Agent、审计；状态枚举与后端现有枚举对齐 |
| `api.ts` | 唯一请求出口：鉴权头、幂等键、错误归一化（401/403/404/409/422/429/500）、端点登记表 |
| `format.ts` | 金额（整数分 → ¥）、日期、时区、脱敏 |
| `permissions.ts` | 管理员能力矩阵（二分：platformAdmin / 非管理员），预留角色槽位 |
| `mock.ts` | 开发模拟数据，**只有 `NEXT_PUBLIC_ADMIN_MODE=mock` 时才加载**，界面强制显示模拟横幅 |

### 组件 `src/components/admin/`

| 文件 | 职责 |
| --- | --- |
| `shell.tsx` | Admin Layout：侧边栏、顶栏、会话守卫、路由级权限 |
| `states.tsx` | loading / empty / error / forbidden / session-expired / unsupported 六态 |
| `ui.tsx` | MetricCard、StatusBadge、DataTable、DetailDrawer、ConfirmDialog、Pagination |
| `chart.tsx` | 内联 SVG 折线/柱状图（替代 Recharts，零依赖） |
| `mock-banner.tsx` | 模拟数据横幅 |

### 路由 `src/app/admin/`

```
layout.tsx            独立 Admin Layout（不复用 customer shell）
admin.css             ad-* 样式，与 ob-* 完全隔离
login/page.tsx        管理员登录入口
page.tsx              经营总览
orders/page.tsx       订单管理（真数据）
finance/page.tsx      财务与收入
approvals/page.tsx    放行与审批中心（真数据 + 真操作）
agents/page.tsx       AI 员工监控
reviews/page.tsx      作品审核中心
customers/page.tsx    客户管理（P1）
plans/page.tsx        套餐管理（P1）
audit-logs/page.tsx   审计日志
```

## 明确不改动的文件

- `src/app/api/[...path]/route.ts` —— 一行不改
- `src/lib/core/*`、`src/lib/commerce/*`、`src/lib/workflows/*` —— 不改
- `src/components/customer/*` —— 不改（`admin.tsx` 保留原样）
- `supabase/migrations/*` —— 不改
- `src/app/(customer)/*` —— 不改

## 分阶段落地顺序

1. 数据层（types → format → permissions → api → mock）
2. 组件层（states → ui → chart → shell）
3. 路由层：layout + login + dashboard
4. orders / approvals（**用真数据**，优先跑通）
5. finance / agents / reviews（空状态 + 缺口提示）
6. customers / plans / audit-logs（P1 只读）
7. typecheck → test → build → 客户平台回归
