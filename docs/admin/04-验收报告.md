- **没有在真实浏览器里截图**：本机没有安装 Playwright 浏览器（`npx playwright install chromium` 未执行），

  只是代码层接通，未在本机跑通端到端。
- **没有验证权限矩阵**：需要至少一个非管理员账号与一个管理员账号。

## 3. 已知问题与风险

1. **审计留痕缺失**（高）：`admin_audit_logs` 表不存在，管理员做收款核验/退款核验时没有可查询的操作日志。
   这是当前唯一能真实执行的写操作，却没有审计——建议列为 A 组下一优先级。
2. **RBAC 不存在**（高）：四角色无法落地，任何「财务只能看财务」的说法目前都不成立。
3. **订单列表是前端筛选**（中）：`/api/core/admin` 固定 `limit 100`，超过 100 条后的数据在后台不可见，
   并且前端筛选不是服务端分页。
4. **财务页全空**（中）：聚合接口缺失，按任务书要求不在前端汇总，因此财务页在 `live` 模式下只有口径说明和缺口提示。
5. **mock 模式仍需真实登录**：`NEXT_PUBLIC_ADMIN_MODE=mock` 只替换数据，不绕过认证。
   本地想看到后台界面，必须先配好 Supabase 并有一个平台管理员账号。
