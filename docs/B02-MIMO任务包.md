# MiMo 任务包：B-02 演示案例创意方向与文案

> 用法：把**整份文件**粘给 MiMo，不要删改"输入事实表"和"输出格式"两节。MiMo 只需回一段 JSON。

---

## 一、你的角色

你是 OneBoss 的创意总监。客户要给一个产品做一套线上宣传物料：一个公开落地页、一张竖版海报（1080×1350）、一张方版海报（1080×1080），外加配套文案。

你的产出会被送去自动渲染。渲染器对字数、用词、事实一致性有硬性校验，**不符合就退回重做**。所以请严格按下面的格式和约束输出。

---

## 二、输入事实表（唯一可信信息来源）

| 字段 | 内容 |
| --- | --- |
| 品牌 | 岚野 LANYE |
| 品类 | 家居 / 折叠家具 |
| 主推产品 | 岚野折木椅 |
| 产品摘要 | 一把可以折起来收进柜子的实木椅 |
| 价格 | ¥1,299 |
| 价格说明 | 含税价，不含运费 |
| 使用场景 | 小户型客餐厅、租房与临时客房 |
| 已确认卖点 1 | 折叠进深 12cm，收起后可靠墙或塞进衣柜缝隙 |
| 已确认卖点 2 | 实木榫卯节点，主受力点用榫卯与金属销复合结构，不是单纯螺丝固定 |

| **未确认项** | 承重上限（尚未提供，**任何文案不得提及或猜测**） |

---

## 三、硬约束（违反任一条即作废）

1. **只准使用事实表里的信息。** 不得新增材质、尺寸、重量、承重、认证、销量、用户评价、保修年限、产地、颜色选项。
2. **"承重上限"是未确认项。** 不得出现"承重""可承重 XX 公斤""稳固承重"等任何表述，也不得用"很结实""随便坐"暗示。
3. **价格必须原样引用 `¥1,299`**，不得改写、不得加"起""低至""仅需"，不得出现折扣、赠品、限时。
4. **禁用绝对化用语**：最、第一、唯一、顶级、国家级、史上、永不、百分百、彻底。不得承诺"用十年""绝不坏"等效果。
5. **中文文案**，使用中文标点（，。、：；），不用 emoji、不用英文感叹号连写。
6. **字数按汉字计**（数字、标点、英文各算 1 个字符）。超一个字符都会被打回。
7. **两套方向必须视觉差异明显**，且必须选用**不同**的 `styleId`，不得是同一套方案的换皮。

## 四、可选的三套视觉预设（选两个，必须不同）

| styleId | 名称 | 版式 | 气质 |
| --- | --- | --- | --- |
| `editorial-minimal` | 精致极简 | `editorial-premium` | 米白底、大留白、衬线标题、克制。适合突出"这是一件值得慢慢看的东西" |
| `future-tech` | 未来科技 | `future-grid` | 深墨绿底、等宽字、参数优先、偏冷。适合突出结构与信息 |
| `young-vibrant` | 年轻活力 | `bold-editorial` | 荧光黄底、超大黑体、高饱和色块、价格最显眼。适合社交平台刷屏 |

## 七、交稿前自检

- [ ] 两个 `styleId` 不同，且版式气质确实不一样（不是同一套换个颜色）
- [ ] 每个字段都没超字数（逐个数，尤其 `headline` ≤8、`subhead` ≤16）
- [ ] 全文没有"承重"二字，也没有暗示承重能力的说法
- [ ] 价格只出现 `¥1,299`，原样，无折扣词
- [ ] 没有绝对化用语（最、第一、唯一、顶级、百分百……）
- [ ] 三个 `highlights` 各对应一条已确认卖点，没有编造
- [ ] 输出是**纯 JSON**，能直接被 `JSON.parse` 解析
